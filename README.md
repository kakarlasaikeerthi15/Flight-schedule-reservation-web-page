# Flight-schedule-reservation-web-page
This project was developed as part of the Skyscanner Frontend Engineer Virtual Internship. It is a React.js-based webpage designed to help users select a travel date using a calendar component. The webpage is built using Skyscanner’s Backpack UI library, which provides reusable design components tailored for travel-related applications.

🌟 Project Overview
The Flight Schedule Webpage allows users to:
✅ View a header section labeled “Flight Schedule”
✅ Select a date from an interactive Backpack Calendar
✅ Click a “Continue” button to proceed further

This project focuses on creating a clean and user-friendly interface, utilizing third-party UI components, and ensuring a responsive design.

🚀 Technologies Used
React.js – For building the user interface
Backpack UI (bpk-component-calendar) – For seamless date selection
CSS & SCSS – For styling and layout customization
Vite – For optimized and fast development.
